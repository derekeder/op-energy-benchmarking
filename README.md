# op-energy-benchmarking

Map of Oak Park Building Benchmarking data 2022-2025.

Village of Oak Park policy page: https://www.oak-park.us/Community/Sustainability-Resilience/Sustainability-Initiatives-Policies/Building-Benchmarking

Data source: https://oakpark-il.beam-portal.org/map/15/properties/

## Running locally

Requires [Docker](https://www.docker.com/).

```bash
docker compose up
```

Then open http://localhost:4000. The site rebuilds and live-reloads on file changes.

If you change the `Gemfile`, rebuild the image with `docker compose build`.

## Data

- `data/op-benchmarking-YYYY.csv`: yearly benchmarking exports from the BEAM portal. To add a year, drop in the CSV and add the year to `benchmarking_years` in `_config.yml`.

  Benchmarking applies to every building of 10,000 ft² or more, but the yearly exports don't always list every covered building. The site (`assets/js/data.js`) builds a master list of covered buildings from every `Oak Park Feature ID` in any year, and shows all of them in every year; a building missing from a year's export counts as not reported for that year. Buildings whose self-reported floor area is under 10,000 ft² in every year they reported are treated as not covered, except Village-owned facilities and a few condo units (reporting their share of a larger covered building) listed in `ALWAYS_COVERED` in `assets/js/data.js`. A building counts as reported only if it has a `Total GHG Emissions` value.
- `data/geocoded.csv`: latitude/longitude for each `CPL Property Address`, generated with the [US Census batch geocoder](https://geocoding.geo.census.gov/geocoder/). After adding or updating a year's CSV, run `python3 scripts/geocode.py`; it only geocodes addresses not already in the file and lists any it couldn't match.
- `data/ccgisdata_-_Parcel_*.geojson`: Cook County parcel polygons (source file, not published with the site).
- `data/parcel_addresses.csv`: PIN-to-address table from the Cook County Assessor's [Parcel Addresses](https://datacatalog.cookcountyil.gov/d/3723-97qp) dataset (PIN and property address only; not published with the site).
- `data/parcels.geojson`: parcel shapes for each benchmarking address, generated by `python3 scripts/match_parcels.py`. Addresses are matched to Assessor addresses exactly, or else to the closest house number on the same side of the same street; candidates more than 250 m from the geocoded point are discarded. Buildings without a parcel match are drawn as points from `data/geocoded.csv`. Re-run the script (after `geocode.py`) when adding a year.
- `data/address_corrections.csv`: hand-reviewed fixes for addresses that don't match automatically (typos, wrong suffixes, buildings the Assessor lists under another address). Give either a `corrected_address` to match instead, or `pins` (space-separated 10-digit PINs) to assign parcels directly, which is needed for tax-exempt public buildings that have no Assessor address. Rows marked "verify" in `note` are best guesses.

## Review: benchmarking list vs. Assessor building sizes

`python3 scripts/assessor_review.py` compares the benchmarking list with building square footage from three Cook County Assessor datasets (commercial valuation, condominium, and residential characteristics; PIN, address, size and use fields only, cached in `data/assessor/`) and writes `reports/assessor_review.csv`. Issue types:

- `not_on_list` / `not_on_list_adjacent`: Assessor buildings of 10,000 ft² or more with no benchmarking building on their parcels (`_adjacent` = a listed building's parcel is within 30 m). `likely_match` names a nearby listed building whose self-reported floor area is within 10% of the Assessor's, which usually means a parcel-matching error to fix in `data/address_corrections.csv`.
- `excluded_assessor_10k`: dropped by the site's under-10,000 ft² rule, but the Assessor says 10,000 ft² or more.
- `assessor_under_10k`: covered on the site, but the Assessor size is under 10,000 ft² (often a building matched to only part of its parcels).
- `excluded_assessor_small`, `no_assessor_size`: for completeness; tax-exempt property (schools, churches, Village facilities) has no Assessor size.

Run it after `match_parcels.py`. The report and Assessor downloads aren't published with the site.
